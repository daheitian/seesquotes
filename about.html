关于这个空间的说明

💡 这是什么？

小信号是一个个人数字花园，用于收集、整理和分享那些容易被忽视但价值巨大的「小信号」——可能是灵光一闪的想法、读到的好书、或是值得记录的观点。

这个名字源于对信息过载时代的反思：我们每天都在接收海量信息，但真正有价值的往往是那些微弱但持续的信号。

"在噪声中寻找信号，在信号中发现意义。"

— 小信号的设计理念

🗂️ 四个板块

💭

见室引号

收集金句、想法和优质信息源。同步自 Notion 数据库，每 6 小时更新一次。

📜

归档

全部金句的时间线归档，支持按关键词筛选。

📚

阅览

微信读书书架、划线与想法，每天自动同步。

✍️

写作

更长形式的思考与文章，基于 GitHub Issues 管理。

⚙️ 技术架构

极简技术栈，追求速度与可靠性：

静态 HTML Vanilla JS CSS Variables GitHub Pages GitHub Actions Notion API 微信读书

数据流：Notion / 微信读书 → GitHub Actions 定时同步 → GitHub Pages 自动部署。无需数据库，无需后端服务器。
